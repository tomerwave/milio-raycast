# Security

Milio is local-first and does not upload thought content. Please do not report security issues in public issues with private data or reproduction content.

Report security vulnerabilities privately through [GitHub Security Advisories](https://github.com/tomerwave/milio-raycast/security/advisories/new). Include the affected version, impact, reproduction steps, and a suggested mitigation when possible.

Do not include real thoughts, LocalStorage exports, credentials, or other personal data in reports. Redact sensitive values before sharing diagnostic output.

Supported security fixes target the latest release and the default branch.
